# 설치 없이 활동지 만들기 — 웹앱 + 챗봇 두 가지 길

`worksheet-render.html` **파일 하나**가 전부입니다. 브라우저로 열면 바로 씁니다.

```
   (A) 앱에서 바로            요청 입력 ─→ [AI] ─→ 검증·조판 ─→ 학생용/교사용 PDF
   (B) 챗봇에서 복붙     Gem/GPT ─ JSON ─→ 붙여넣기 ─→ 검증·조판 ─→ 학생용/교사용 PDF
```

| | (A) 앱에서 바로 | (B) 챗봇에서 복붙 |
|---|---|---|
| 준비물 | API 키 1개(직접 발급) | Gemini Gem 또는 ChatGPT 계정 |
| 손이 가는 정도 | 요청 한 줄 → 끝 | 요청 → 복사 → 붙여넣기 |
| 돈 | 쓴 만큼(무료 한도 있음) | 구독으로 이미 냄 |
| 학교 방화벽 | API 가 막히면 못 씀 | 챗봇만 되면 됨 |

**둘 다 같은 규격·같은 렌더러**를 씁니다. 상황에 맞는 쪽을 쓰면 되고, 섞어 써도 됩니다.

## 준비 — 렌더러 열기 (공통, 한 번만)

- **주소로 바로 쓰기**: <https://dacisosl.github.io/worksheet_web_app/> — 이 주소를 동료 교사에게 그대로 보내면 됩니다.
- **파일로 쓰기**: [`worksheet-render.html`](worksheet-render.html) 을 내려받아 더블클릭(브라우저에서 열림).
  인터넷이 끊긴 교실에서도 열립니다.

권장 브라우저는 **Chrome / Edge** 입니다(인쇄 조판이 가장 정확합니다). 파일은 약 800KB(전송 시
gzip 약 210KB)이고 성취기준 3,285건이 안에 들어 있어 **성취기준 조회는 오프라인에서도 됩니다**.

## (A) 앱에서 바로 만들기

### 1. 키 넣기 (한 번만)

왼쪽 위 **⚙(설정)** → **AI 연결** 탭에서 서비스를 고르고, 키를 붙여넣고 [저장] →
[목록 새로고침]으로 모델을 고릅니다.

| 서비스 | 키 발급 | 특징 |
|---|---|---|
| **Google Gemini API** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | 무료 한도가 있어 시작하기 쉽습니다. `flash` 계열이 빠르고 저렴합니다 |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | 한 키로 여러 회사 모델(Claude·GPT·Gemini·오픈모델)을 골라 씁니다. 목록에서 `무료` 표시 모델도 있습니다 |

모델 목록에는 `[무료]` 또는 `[$0.30/1M]` 처럼 값이 표시되고, 활동지는 JSON 출력이라
**구조화 출력을 지원하는 모델이 먼저** 나옵니다. `JSON 미지원` 이라고 표시된 모델은 실패할 수 있습니다.

> 키는 **이 브라우저(localStorage)에만** 저장되고 선택한 서비스로만 전송됩니다. 서버를 거치지
> 않습니다. 공용 PC 에서는 쓰고 나서 [지우기]를 누르세요. 활동지 요청에 **학생 실명·개인정보를
> 넣지 마세요**(요청 내용은 그 회사 서버로 갑니다).

### 2. 요청하고 인쇄하기

1. 왼쪽 아래 입력창에 평소 말로 적고 **Enter**(첫 화면의 예시 버튼을 눌러도 됩니다):
   ```
   중2 과학 옴의 법칙 활동지 만들어줘
   ```
   앱이 **해당 교과의 성취기준을 프롬프트에 함께 실어** 보냅니다(그래서 모델이 성취기준 코드를
   지어내지 못합니다). "중2 과학"처럼 **학교급·교과를 넣으면** 그 교과 전체를 보내 정확해집니다.
2. 초안이 오면 자동으로 검증·조판되고 오른쪽에 A4 미리보기가 나옵니다.
   **[학생용] / [교사용]** 을 확인한 뒤 **[인쇄 · PDF 저장]**.
3. 고칠 것은 그대로 이어서 말합니다(앞 활동지를 기억합니다):
   ```
   3번 문항 빼고 마지막에 성찰 질문 추가해줘
   문항을 5개로 줄이고 더 쉽게 써줘
   문항을 두 개씩 나란히(2단) 놓아서 장수를 줄여줘
   ```
   "복습·정리·기본 문제"라고 말하면 소주제를 모두 다루는 3~4장짜리로, 그 밖에는 한 차시용 1~2장으로
   만듭니다. 문항은 기본적으로 한 줄에 하나씩이고, **2단은 요청할 때만** 씁니다.
4. 다른 주제로 넘어갈 때는 왼쪽 위 **＋** 를 눌러 대화를 비웁니다.

## (B) 챗봇에서 만들어 붙여넣기

### 1. Gem 만들기 (5분, 한 번만)

1. Gemini → **Gem 만들기**, 이름은 `활동지 만들기`
2. **지시**: [`GEM_INSTRUCTIONS.md`](GEM_INSTRUCTIONS.md) 의 `---` 아래 내용을 전부 붙여넣기
3. **지식(파일 업로드)**: `knowledge/` 에서 아래를 올립니다.
   - `worksheet-json-spec.md` ← **필수**(저작 규격)
   - `example-worksheet-science.json`, `example-worksheet-social.json` ← 완성 예시
   - `standards-*.md` ← **본인이 가르치는 학교급·계열만**

   | 파일 | 내용 |
   |---|---|
   | `standards-초등학교.md` | 초등 전 교과 653건 |
   | `standards-중학교.md` | 중학교 전 교과 580건 |
   | `standards-고등-국어영어외국어.md` | 국어·영어·제2외국어·한문 818건 |
   | `standards-고등-수학과학정보.md` | 수학·과학·정보 532건 |
   | `standards-고등-사회역사도덕.md` | 사회·역사·도덕·경제 376건 |
   | `standards-고등-체육예술기술교양.md` | 체육·예술·기술가정·교양 326건 |

   > 전부 올리지 마세요. 학교급이 섞이면 챗봇이 엉뚱한 학년의 성취기준을 물어옵니다.
4. 저장 → **공유**로 동료 교사에게 링크를 보낼 수 있습니다.

**ChatGPT** 는 "GPT 만들기"에 같은 지시문·같은 파일을 넣으면 됩니다.
**Claude** 는 프로젝트를 만들어 지시문을 "프로젝트 지침"에, 파일들을 프로젝트 지식에 넣으세요.

### 2. 복사해서 붙여넣기

1. 챗봇에 `중2 과학 옴의 법칙 활동지 만들어줘`
2. 답변의 **```json 코드 블록**을 복사(코드 블록 오른쪽 위 복사 버튼)
3. 앱에서 **⚙ → JSON 직접 넣기** 탭에 붙여넣고 **[검사 · 조판]**
   (파일을 그 칸에 끌어다 놓아도 됩니다. AI 키가 없어도 이 경로는 그대로 동작합니다.)
4. 확인하고 **[인쇄 · PDF 저장]**

## 한글·워드에서 고치기 — [DOCX]

오른쪽 위 **[DOCX]** 를 누르면 현재 탭(학생용/교사용)의 **편집용 워드 문서**를 내려받습니다.
한글(HWP)은 이 docx 를 그대로 열 수 있고, 열어서 **hwp/hwpx 로 저장**하면 됩니다.

편집용이라 인쇄물과 같지는 않습니다.

| 그대로 넘어가는 것 | 달라지는 것 |
|---|---|
| 제목·소제목(번호)·학습 목표·지시문 | **쪽 나눔** — 워드/한글이 다시 계산합니다 |
| 개념 상자·문항 상자(표로), 표, 답란(밑줄) | **수식** — 읽을 수 있는 평문으로 바뀝니다(`\dfrac{a}{b}` → `(a)/(b)`, 첨자는 위·아래 첨자) |
| 교과 색, 학생용 정답 제거 | **그림형 조직자**(벤다이어그램 등) — 자리 표시만 남습니다 |

내려받은 뒤 대화에 "변환하지 못한 것" 안내가 나오면 그 부분만 문서에서 손보세요.
**인쇄물은 [인쇄 · PDF 저장]이 정확합니다** — DOCX 는 고칠 때만 쓰세요.

## 인쇄 설정

오른쪽 위 **[인쇄 · PDF 저장]** 을 누르면 브라우저 인쇄창이 열립니다.
**대상 = PDF로 저장**, **여백 = 없음**, **배율 = 100%**, **배경 그래픽 = 켜기** 로 두세요.
학생용·교사용을 각각 한 번씩 인쇄하면 2벌이 됩니다.
(미리보기는 화면 폭에 맞춰 축소해 보여 주지만 **인쇄는 항상 실제 A4 크기**로 나갑니다.)

## 대화에 나오는 진행 카드

활동지를 만들 때마다 대화에 접힌 카드 한 줄이 생깁니다(`● 검사 · 조판 완료`). 펼치면 앱이 무엇을
했는지 다 보입니다. 점 색이 뜻입니다.

- **초록** — 통과(조판 완료, 정답 제거 확인)
- **노랑** — 경고(교과를 못 좁혔거나, 응답이 끊겼을 수 있음). 결과는 나옵니다
- **빨강** — 막힘. 카드가 저절로 펼쳐집니다. 그 줄을 그대로 복사해 "이 부분 고쳐서 다시 줘" 라고 하세요

회색 줄은 앱이 자동으로 맞춘 것(예: 표 머리글 표시)이라 그냥 넘어가도 됩니다.

## 무엇이 보장되고, 무엇이 보장되지 않나

렌더러가 **기계적으로 보장**하는 것 — AI 를 쓰든 챗봇을 쓰든 같습니다.

- **학생용에 정답이 남지 않습니다.** 정답 개체를 트리 수준에서 물리적으로 제거하고, 남은 흔적이
  있으면 학생용 출력 자체를 막습니다(교사용만 나옵니다).
- **A4 쪽 넘침이 없습니다.** 실제 브라우저 높이를 재서 쪽을 나눕니다. 표·조직자는 쪼개지지 않습니다.
- **교과 색·서식이 매번 같습니다.** AI 가 색이나 CSS 를 만들지 않습니다.
- **성취기준을 지어낼 수 없습니다.** 코드·원문은 내장 대장에서 온 것만 프롬프트에 실립니다.
  (다만 그중 **어느 것을 고르는지**는 AI 의 판단입니다.)
- 카탈로그 밖의 개체·문항 유형은 통과하지 못합니다.

**교사가 반드시 확인해야 하는** 것:

- 사실 관계(연도·수치·실험값·인물), 학년 수준과 어휘 난이도
- 고른 성취기준이 이 차시에 맞는지
- 지문·이미지 저작권 — 실존 작품 원문은 AI 가 넣지 않습니다. 교사가 직접 넣고 출처를 적으세요
- 교사용 정답이 맞는지

## 잘 안 될 때

| 증상 | 원인·해결 |
|---|---|
| `JSON 을 읽을 수 없습니다` | 설명 문장이 섞여 복사됐습니다. `{` 로 시작해 `}` 로 끝나는 부분만 복사하세요 |
| 학생용 탭이 눌리지 않음 | 정답 누출로 학생용이 막힌 상태입니다. 대화의 빨간 카드를 확인하세요 |
| `구조 검증에서 막혔습니다` | 빨간 줄을 그대로 AI/챗봇에 붙여 "고쳐서 다시" 요청하세요 |
| `학생용에서 정답 흔적이 발견돼…` | 정답을 발문이나 강조상자에 썼습니다. "정답은 answerKey 에만 넣어서 다시 줘" |
| `API 키가 인증되지 않았습니다` | ⚙ → AI 연결에서 키를 다시 저장하세요. 서비스(Gemini/OpenRouter)와 키가 맞는지 확인 |
| `키에 권한이 없습니다` | Gemini: Google Cloud 에서 Generative Language API 사용 설정·지역 제한 확인 |
| `사용 한도를 넘었습니다` | 무료 한도 초과입니다. 잠시 뒤 다시 하거나 다른(저렴한) 모델을 고르세요 |
| `크레딧이 부족합니다` | OpenRouter 잔액을 채우거나 `무료` 표시 모델을 고르세요 |
| `선택한 모델을 쓸 수 없습니다` | ⚙ → AI 연결 → [목록 새로고침] 후 다른 모델 선택 |
| `응답이 길이 제한에 걸려…` | "문항을 5개로 줄여줘"처럼 분량을 좁혀 다시 요청 |
| 성취기준이 이상함 | 요청에 학교급·교과를 넣으세요("중2 과학 …"). 또는 "성취기준은 [9과14-02] 로 해줘" |
| 표 칸이 비어 나옴 | 표 셀을 `{"text": "…"}` 로 달라고 하세요(앱이 자동 교정하지만 안 되는 경우도 있음) |
| 수식이 `$V=IR$` 그대로 보임 | 인터넷 연결이 필요합니다(수식 표시 도구를 인터넷에서 불러옵니다) |
| 글꼴이 다르게 보임 | 오프라인이라 기본 글꼴로 바뀐 것입니다. 인쇄에는 문제없습니다 |

성취기준 후보가 왜 그렇게 나왔는지 보고 싶으면 브라우저 콘솔(F12)에서:

```js
WSG_DEBUG.searchStandards('중2 과학 옴의 법칙', 40)
```

## NotebookLM 은 어디에 쓰나

NotebookLM 은 **활동지를 만들지 못합니다**(파일·조판 출력이 없습니다). 성취기준·교육과정 문서를
소스로 넣어 **찾고 확인하는 데** 쓰면 좋습니다. `standards-*.md` 를 소스로 넣고 "중2 과학에서 전기
회로 관련 성취기준을 모두 찾아줘"처럼 물으면 근거 인용이 붙습니다. 찾은 코드를 앱/Gem 에 알려주세요.

## 파일을 다시 만들려면 (관리자용)

```bash
npm run build:gem
```

`worksheet-render.html` 은 `src/` 의 렌더 코어(개체→HTML, 정답 제거, 쪽 나눔)와 프롬프트 문서
(`tools/ai-system-prompt.md`, `gem/knowledge/worksheet-json-spec.md`), 성취기준 대장을 구워 넣은
산출물입니다. **직접 고치지 마세요** — 원본을 고치고 다시 빌드하면 됩니다.

챗봇이 만든 JSON 을 브라우저 없이 점검하려면:

```bash
node tools/check-authored-json.mjs 활동지.json --html out
```
